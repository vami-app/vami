# Agent Rules for this Project

## Absolute Implementation Alignment
You must NEVER implement architectural changes, refactors, or patterns partially. 
When introducing a new pattern (e.g., environment validation, error boundaries, caching, database connection paradigms), you must audit the ENTIRE repository and ensure 100% of the codebase is aligned with the new pattern. 
If the pattern cannot be aligned across the entire project simultaneously, do not implement the change at all. No partial implementations or technical debt are allowed under any circumstances.
